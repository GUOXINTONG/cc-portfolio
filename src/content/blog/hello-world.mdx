Welcome to my new blog! This is the first post on my freshly built portfolio website using [Astro](https://astro.build), a modern static site generator that delivers lightning-fast performance.

## Why Astro?

Astro offers several compelling advantages for content-focused websites:

- **Performance-first**: Zero JavaScript by default, islands architecture
- **Content-focused**: Built-in support for Markdown and MDX
- **Framework-agnostic**: Use React, Vue, Svelte, or vanilla components
- **SEO-friendly**: Static HTML generation means better search engine visibility
